# image-markup-kit

Photo markup and multi-photo boards for React: pen, highlighter, shapes, arrows, polylines and curves, text and
sticky notes, flattened to one JPEG or PNG.

A port of [ImageMarkupKit](https://github.com/thnhsng/ImageMarkupKit) (Swift/UIKit) to the web. It reads and writes
the same `document.json` (schema 1), so markups can move between the two.

> Work in progress: not published yet.
